no account signup, and no license key — the CLAUDE.md constraint this list
exists to enforce. Updated as phases add dependencies; source of truth for

## Enrichment data

DB-IP City/ASN Lite (CC BY 4.0) was CLAUDE.md's pinned source, but this
build generates a **synthetic** CIDR-range geo/ASN dataset instead — see
`docs/DECISIONS.md` D-002 for why (no .mmdb encoder available in a
reader-only ecosystem, and determinism for the demo). `tools/gen-enrichment`
generates it from a fixed seed; nothing is scraped or downloaded. IOC,
MITRE-map, asset and identity datasets are likewise entirely synthetic,
generated by the same tool — never a real threat feed or real CMDB/IAM
export.
